# image-edit

使用 Python Pillow 進行程式化圖像處理：馬賽克/模糊區域、繪製標註、裁剪、調整大小，並生成驗證用的前後對比條。

## 快速開始

```bash
# 檢查依賴
~/.local/bin/python3 -c "from PIL import Image" 2>/dev/null ||   pip3 install Pillow --break-system-packages
```

## 核心操作

### 馬賽克（像素化）
使用基於區塊的像素化的主要隱私保護技術：
- 縮小區域 → 用 NEAREST 濾鏡放大回原尺寸
- 可調整的區塊大小：4-6（細微）、8-10（標準）、12-16（重度）、20+（最大）

### 高斯模糊
使用 PIL 的 `ImageFilter.GaussianBlur` 的替代隱私技術：
- 可配置的模糊半徑，實現平滑的匿名化

### 標註
在套用編輯前標記區域：
- 紅色框用於突顯
- 文字標籤用於識別
- 用於預覽/驗證

### 對比條
並排縮放裁剪，用於驗證：
- 前後視覺對比
- 縮放以便輕鬆檢查
- 確認隱私保護效果

## 工作流程：目標馬賽克

1. **偵測** — 使用 `/ocr` 技能找到目標文字位置
2. **預覽** — 在副本上繪製紅色矩形，儲存為 `_preview.png`
3. **套用** — 對每個偵測到的區域套用馬賽克（含填充）
4. **驗證** — 為每個區域組生成對比條
5. **最終檢查** — 在輸出上重新執行 OCR，確認文字無法讀取
